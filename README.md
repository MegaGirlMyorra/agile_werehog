# Agile Werehog
Mod for Sonic Unleashed Recompiled to make the Werehog more enjoyable to control

# Changes
- Faster max walking speed (might be lowered later)
- MUCH FASTER dashing speed. Use in short bursts for maximum control and speed
- Higher jump and double jump. Allows for some skips.
- Slightly lower gravity
- All B-mashing actions only require one B-press
- Much faster box pushing
- Faster movement while guarding
